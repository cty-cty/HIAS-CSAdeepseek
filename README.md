# HIAS-CSA (Course Selection Assistant)

国科大杭州高等研究院 2026-2027 学年课程预选模拟工具。

## 项目介绍

HIAS-CSA 是面向国科大杭州高等研究院 2026 级研一新生的课程查询与预选课模拟工具，整合了已整理的 **2026 秋季学期 158 门课程**与**依据培养方案整理的 2027 春季计划课程**，帮助同学查询课程、检查时间冲突、统计学分、体检培养进度并生成个人模拟课表。

项目中的课程和培养方案数据来自已有课表、学院课程设置（含开课学期）与选课须知材料的整理，仅供课程查询、选课规划和模拟使用，不代表学校最新或最终安排。正式选课前请务必自行核对，并以学校教务系统、培养方案原文件和正式通知为准。

**春季计划课程说明（重要）**：内置的 2027 春季（`2027-spring`）课程属于“依据 2026—2027 培养方案整理的春季计划课程”，数据状态标记为 `planned`。它们可用于：判断某培养要求春季是否仍有课程可选、跨学期培养规划、提示“可留至春季完成”。**具体课程时间、班次、容量、教师与最终开设情况，一律以春季正式课表及教务系统为准**；公开的公共选修课名单发布前，本工具不预置虚构的具体公选课程。获得正式春季课表后，可在“数据管理”中导入，系统会按 `officialCode → canonicalCourseId → 课程名+所属专业` 的顺序把计划课程升级为正式课表课程，避免计划/正式重复显示两份。

网页默认通过 GitHub Pages 在线使用，也可以按需下载为单文件离线网页。无需登录或安装软件，已选课程保存在当前浏览器中。

## 主要功能

- **多条件课程查询**：支持按课程名称、课程编码、教师、教室等关键词搜索，并可按开课院系、所属学科/专业、课程类别和上课星期筛选。
- **完整课程信息**：集中展示课程学分、学时、任课教师、开课院系、所属学科、上课时间、周次、教室、考试方式、授课方式及选课人数等信息。
- **选课工作区**：首页直接进入课程列表，搜索和筛选仅在选课页显示；筛选条件可逐项取消，“已选”入口会清除其他筛选，完整展示当前学期的选课。
- **已选课程与学分统计**：点击课程卡片上的“加入课表”按钮即可预选，电脑端右侧方案栏、手机端底部快捷栏实时展示门数和学分。加入、移除、换班和清空后支持撤销上一步操作。
- **自动检查课程冲突**：发现上课时间和教学周次重叠时，会明确提示哪两门课程发生冲突，并显示具体冲突时段。
- **一键寻找替代班次**：若同一门课程存在其他无冲突班次，可直接查看并选择替代班次，快速调整选课方案。
- **选课方案体检**：结合当前培养方向检查学期有效学分、课程冲突、核心课与专业课、公选课、创新创业模块、体育课限制及课程属性设置情况。
- **学位课属性**：可将每门已选课程标记为学位课、非学位课或未确定；研讨课、实验课、实践课和科学前沿讲座会按规则限制为非学位课，并按学期保存在浏览器中。
- **课程归属口径**：HIAS讲堂（人文系列讲座）计入公共选修体系，不计入专业非学位；科学前沿讲座计入专业非学位，不计入公共选修。两者都不计入秋季/春季有效学分最低 10 学分。
- **模拟周课表**：可按照第 1—20 周分别查看个人课表，课程按星期和节次排列，发生冲突的课程会用红色标出。
- **培养要求参考**：结合培养方案与秋季课表，展示不同培养方向的学分要求、核心课程和专业课程，并统计本学期已选课程对培养方案课程库的覆盖情况。
- **考试压力分析**：按照闭卷、开卷、报告/论文、实践/技能及其他考核方式对已选课程分类，辅助平衡不同类型的学习和考核压力。
- **选课须知**：集中展示 2026-2027 学年选课开始与截止时间、学期选课学分门槛、核心课/专业课认定、公选课限制、增退选与学位属性变更时限、课程评估和咨询渠道。
- **导出选课结果**：按文件夹中的 `课表模板.xlsx` 导出 CSV，列顺序为“课程名称、星期、开始节数、结束节数、老师、地点、周数”，每个上课安排单独占一行。
- **WakeUp 课程表导入**：导出的 CSV 与 WakeUp 课程表模板字段和行结构一致；确认课程、时间和周数符合实际后，可直接导入 WakeUp 使用。
- **本地保存**：选择结果会自动保存在当前电脑的浏览器中，不会上传到项目服务器。
- **清空当前学期选课**：可在方案栏或“已选”列表中清空课程，操作前会提示学期和课程门数并要求确认；其他学期和历史已修记录保留。
- **培养设置与补充建议**：首次打开自动弹出“培养设置”，确认培养方向及英语免修免考资格；点击“完成设置，开始选课”后，同一浏览器不再自动弹出，仍可从顶部手动修改。未完成就关闭窗口时，下次打开仍会提醒。补充建议通过方案栏或“已选”列表按需打开，连续选课时不会自动弹窗。
- **英语免修免考学分**：选择“已获得”后，按“已获得 / 历史已修”直接计入硕士学位英语 3 学分（归属 2026 秋季已获得学分）——不进入任何学期的“预选课程学分合计”，培养要求进度同步统计，也不会增加课程门数或生成课表条目。已选或历史已修英语课程不会重复计分；取消资格后重新按实际课程计算。
- **一键更新课程数据**：在“当前课程数据学期”区域选择新的课程数据 JSON，即可在浏览器本地加载新学期或修订后的课程表；更新同一学期时会按课程编码尝试保留已选课程，并提示未匹配项目。
- **按学期隔离选课记录**：不同学期拥有独立的已选课程、学分统计、冲突检查和模拟课表，切换学期不会串课。
- **选课方案体检（红黄绿三色语义）**：红色 = 本学期必须处理（时间冲突、同课多班、有效学分 <10、体育公选超 1 门、一年级秋季必修漏选等）；黄色/绿色 = 培养方案进度（核心/专业课门数、学位学分、公共选修体系等），未完成显示“后续学期仍需完成 / 可留待春季”，不当作本学期选课错误；琥珀 = 待确认事项（跨专业学位课、资料口径不一致、博士培养类型等）。
- **智能补全方案**：以“已选课程默认锁定”为前提，读取与体检完全相同的培养缺口引擎，生成最多 3 个方案（培养要求优先 / 均衡 / 时间集中），自动为多班次课程选择无冲突班次；应用前显示新增清单并要求确认，不会自动删除或替换已选课程。
- **学位认定四态**：eligible（可直接确认）/ approval_required（需导师/学院审核）/ verification（资料不足或口径不一致，待核验）/ ineligible（规则明确禁止）。只有 eligible 自动计入“确定完成”；“不推荐/需审批/资料未确定”均不等于“不能选”。
- **培养规则与推荐分层**：学校硬规则与学院培养方案由确定性代码执行（纯函数模块）；推荐策略、工作量提示与“可留至春季”仅为产品建议，不伪装成学校规定。
- **多学期数据状态**：每门课程可带 `scheduleStatus`（`planned`/`confirmed`）与 `officialCode`；占位编码（`SP2027-xxx`）只作内部使用，界面不会把它当成学校正式课程编码。
- **博士培养类型**：直博/硕博连读与普通招考博士（普博）口径不同。普博的学院级规则在现有正式材料中未明确时，页面按“校级口径 + 待确认”展示，绝不自动套用“2 门核心 + 2 门专业”。
- **可扩展培养方案**：在“培养方案参考”页导入其他学科或专业的培养方案 JSON。导入内容只保存在当前浏览器，不会覆盖内置方案。
- **学院分组筛选**：培养方向菜单与课程学科/专业筛选按学院自动生成一级分组，分组来自培养方案里的可选 `college` 字段与内置学院目录；新增学院只需补充方案数据，不需要修改页面组件。未填写 `college` 的旧方案安全归入“其他培养方案”。
- **意见反馈 / 留言**：新增「意见反馈」标签页，可选择留言类型（功能建议 / 课程数据纠错 / 使用问题 / 其他），填写标题、内容与可选联系方式。内容只保存在本机浏览器；点击“提交到 GitHub Issue”会打开预填好标题与正文的新建 Issue 页面（需要 GitHub 账号，最后一步由本人确认），也可以只保存到本机、复制内容或导出为 Markdown 后自行发送。留言不会自动上传，附带的环境信息仅含学期、培养方向、已选课程数量与学分、所在页面、页面地址、浏览器标识与记录时间。

### 更新课程数据文件格式

课程数据文件可以直接使用项目中的 `app/courses.json` 数组，也可以使用带学期信息的 JSON：

```json
{
  "termId": "2027-spring",
  "label": "2027 春季",
  "audience": "适用对象以对应培养方案和学校通知为准",
  "courses": []
}
```

其中 `courses` 内的课程字段需与 `app/courses.json` 保持一致；`audience` 可选，用于更新页面顶部的适用对象提示。如果没有提供 `termId` 或 `label`，网页会根据文件名建立学期名称。

可选字段（推荐）：
- `officialCode`：学校正式课程编码（无则留空/`null`），不要把内部占位码当作正式编码；
- `scheduleStatus`：`planned`（依据培养方案整理的计划课程）或 `confirmed`（正式课表课程）；
- `semesterNote`：`spring` / `fall` / `both`，用于秋春机会判断与跨学期规划；
- 未知信息（时间/容量/已选人数/考核方式等）请保持空或 0，界面会显示“待公布/未提供”，不会被当成“已满”或“不能选”。

当用户为“2027-spring”导入正式春季课表 JSON 时，页面会按 `officialCode → canonicalCourseId → 课程名+所属专业` 顺序把内置春季计划课程升级为正式课程，并保留已选记录（避免计划课程与正式课程重复出现两份）。

### 导入其他培养方案

在“培养方案参考”页点击“导入培养方案 JSON”，可上传一个方案数组，或上传包含 `plans` 字段的 JSON。每个方案至少需要以下字段：

```json
{
  "plans": [
    {
      "id": "example-master",
      "label": "示例方向 · 专硕",
      "degree": "专业型硕士",
      "program": "示例专业",
      "college": "示例学院",
      "code": "0854 示例代码",
      "totalCredits": 25,
      "publicRequiredCredits": 8,
      "degreeCourseCredits": 12,
      "professionalNonDegreeCredits": 2,
      "publicElectiveCredits": 2,
      "innovationCredits": 1,
      "coreMinimum": 2,
      "professionalMinimum": 2,
      "coreCourses": ["核心课程名称"],
      "professionalCourses": ["专业课程名称"],
      "source": "培养方案文件名称或来源说明"
    }
  ]
}
```

`publicRequiredCredits`、`professionalNonDegreeCredits` 或 `innovationCredits` 未在材料中明确时可填 `null`，网页会显示“材料未明确”或“不限”。当前内置的人工智能、材料工程培养方向按与光电信息工程相同的公共必修要求计为 8 学分。导入后网页会显示方案来源和更新时间，并按课程名称统计本学期课表中的可匹配课程。

`college` 是可选字段，用于培养方向菜单与课程学科/专业筛选的学院一级分组。系统内置学院目录，当前包括基础物理与数学科学学院、物理与光电工程学院、化学与材料科学学院、生命与健康科学学院、药物科学与技术学院、环境学院、分子医学院和智能科学与技术学院。新增学院的培养方案时，只需在每个方案里填写所属学院名称；页面会依据数据自动生成对应分组，**不需要修改筛选组件代码**。旧版自定义方案没有该字段时，会安全归入“其他培养方案”分组。

## 导入 WakeUp 课程表

1. 先在课程列表中确认已选课程、班次、上课地点、星期、节次和周数均符合学校最终安排。
2. 点击右上角“导出 CSV”，保存生成的 CSV 文件。
3. 打开 WakeUp 课程表的导入功能，选择该 CSV 文件并检查导入预览。
4. 如学校课表或班次有调整，请重新核对后再导入；本工具不会替代学校正式选课系统。

## 数据与免责声明

- 课程信息依据 2026 秋季学期课表、物光学院 2026—2027 课程设置及《研究生课程学习与选课须知(2026-2027)》等正式材料整理。
- 春季课程为“培养方案计划课程”（来源：学院课程设置中标注春/秋春的课程 + 选课须知中的开课学期表），课程时间、班次、容量、教师与最终开设情况以春季正式课表与教务系统为准；公共选修课具体名单以届时教务系统为准。
- HIAS讲堂（人文系列讲座）计入公共选修体系，不计入专业非学位；科学前沿讲座计入专业非学位课（专业选修，非学位），不计入公共选修。两者都不计入秋季/春季有效学分最低 10 学分。
- 《工程伦理》为工程硕士公共必修非学位课程；跨专业 1/2/3 类课程可作为“需导师/学院审核”的候选，不会被直接判为不能作为学位课。
- 一年级（2026 级硕士/直博/硕博连读）须在秋季学期修读《新时代中国特色社会主义理论与实践》《自然辩证法概论》。
- 博士口径：直博/硕博连读按学院“博士”行（≥38 学分、公共必修 11、专业学位 ≥16、核心/专业各 ≥2）整理；普通招考博士（普博）的学院级规则在现有材料中未明确时按待确认展示，不自动套用 2+2。
- 选课规则与时间节点参考《国科大杭州高等研究院课程学习及选课须知-2026-2027学年》整理，仅用于模拟选课时快速查阅。
- 本工具仅适用于国科大杭州高等研究院 2026 级研一新生，其他年级、入学年份或培养阶段请勿直接套用。
- 本项目为非官方选课规划辅助工具，不代表国科大杭州高等研究院或学校选课系统。
- 离线数据不会自动更新，课程信息可能存在延迟、遗漏或整理误差，课程余量和选课人数也不是实时数据。
- 培养要求统计表示已选课程与当前内置培养方案课程库的匹配和覆盖情况，不等同于正式的毕业资格审核。
- 最终课程安排、培养要求、考试信息及选课结果，请以学校正式通知、培养方案文件和选课系统为准。
- 已选课程仅保存在使用者当前浏览器的本地存储中，不会上传到本项目或其他服务器。
