# HIAS-CSAdeepseek (Course Selection Assistant)

国科大杭州高等研究院 2026 秋季课程预选模拟工具。

## 项目介绍

HIAS-CSAdeepseek 是面向国科大杭州高等研究院 2026 级研一新生的课程查询与预选课模拟工具，整合了已整理的 **2026—2027 学年（秋）第一学期** 158 门课程信息，帮助同学查询课程、检查时间冲突、统计学分并生成个人模拟课表。学期选择采用学校系统的“学年(季节+第X学期)”命名（如 2026—2027学年(秋)第一学期，默认即此学期）。

项目中的课程和培养方案数据来自已有课表及相关材料的整理，仅供课程查询、选课规划和模拟使用，不代表学校最新或最终安排。正式选课前请务必自行核对，并以学校教务系统、培养方案原文件和正式通知为准。

网页默认通过 GitHub Pages 在线使用，也可以按需下载为单文件离线网页。无需登录或安装软件，已选课程保存在当前浏览器中。

## 主要功能

- **多条件课程查询**：支持按课程名称、课程编码、教师、教室等关键词搜索，并可按开课院系、所属学科/专业、课程类别和上课星期筛选。
- **完整课程信息**：集中展示课程学分、学时、任课教师、开课院系、所属学科、上课时间、周次、教室、考试方式、授课方式及选课人数等信息。
- **已选课程与学分统计**：点击课程卡片上的星标即可加入预选课表，页面会实时汇总已选课程数量和总学分。
- **自动检查课程冲突**：发现上课时间和教学周次重叠时，会明确提示哪两门课程发生冲突，并显示具体冲突时段。
- **一键寻找替代班次**：若同一门课程存在其他无冲突班次，可直接查看并选择替代班次，快速调整选课方案。
- **模拟周课表**：可按照第 1—20 周分别查看个人课表，课程按星期和节次排列，发生冲突的课程会用红色标出。
- **培养要求参考**：结合培养方案与秋季课表，展示不同培养方向的学分要求、核心课程和专业课程，并统计本学期已选课程对培养方案课程库的覆盖情况。
- **学分达成度仪表盘**：按公共必修课、专业学位课、专业非学位课、公共选修课、创新创业课逐项显示已选/要求学分进度条与总学分完成度，缺多少学分一目了然；自动识别创新创业模块课程（如《创业管理》《创业启程》等，属性为公共选修课，专业学位硕士须修 1 学分）。
- **硕士学位英语免修开关**：符合教务处免修条件（如考研英语一≥70、英语二≥75、CET-6≥600、雅思≥7、托福≥100）并获准认定的同学，可在页面顶部汇总卡一键开启免修：公共必修课自动按已获 3 学分计算（成绩记 EX），英语班级课程不再排入课表与选课推荐，已选的英语班课会自动移出。
- **选课须知**：内置 2026 秋季学期选课窗口倒计时与关键节点（9 月 4 日—9 月 18 日在线选课及审核）、学位课规则、公共必修与英语免修说明、公选/讲座学分规则、考核红线与咨询联系方式，内容整理自教务处《研究生课程学习与选课须知（2026-2027 学年）》。
- **历史已修学分补录**：可导入上学期课程数据 JSON（自动按课程属性汇总学分），也可直接按课程属性录入已修学分；达成度按“已修 + 本学期已选”累计统计，便于规划后续学期。导入后首页汇总卡片会同步显示“已修 + 本学期”的累计学分与毕业进度。
- **考试压力分析**：按照闭卷、开卷、报告/论文、实践/技能及其他考核方式对已选课程分类，辅助平衡不同类型的学习和考核压力。
- **导出选课结果**：按文件夹中的 `课表模板.xlsx` 导出 CSV，列顺序为“课程名称、星期、开始节数、结束节数、老师、地点、周数”，每个上课安排单独占一行。
- **WakeUp 课程表导入**：导出的 CSV 与 WakeUp 课程表模板字段和行结构一致；确认课程、时间和周数符合实际后，可直接导入 WakeUp 使用。
- **本地保存**：选择结果会自动保存在当前电脑的浏览器中，不会上传到项目服务器。
- **清空当前学期选课**：可在右上角汇总卡片中一键清除当前学期的已选课程，不影响其他学期。
- **一键更新课程数据**：在“当前课程数据学期”区域选择新的课程数据 JSON，即可在浏览器本地加载新学期或修订后的课程表，无需重新改代码。
- **按学期隔离选课记录**：不同学期拥有独立的已选课程、学分统计、冲突检查和模拟课表，切换学期不会串课。
- **数据备份与恢复**：可将学期数据、各学期选课记录与已修学分一键导出为 JSON 备份，换浏览器或电脑后可随时恢复，避免本地数据丢失。
- **智能选课建议**：依据当前培养方向严格约束自动推荐——专业学位课仅限本专业课程库、专业非学位课仅限本学院、同课程只推最优班次、已选与冲突课程一律排除、英语免修后不再推荐英语课；按公共必修/学位课/非学位课/公选/创新学分缺口依次补足（学位课优先满足核心/专业课门数），并给出推荐理由与无法满足时的原因说明。

## 本地运行

```bash
npm install
npm run dev
```

运行 `npm test` 可执行核心逻辑（冲突检测、CSV/课程数据/备份解析等）的单元测试。

## 生成离线版

```bash
npm run build:offline
```

生成后的单文件网页位于项目上一级目录，可直接使用现代浏览器打开，也可以复制给其他同学使用。

### 更新课程数据文件格式

课程数据文件可以直接使用项目中的 `app/courses.json` 数组，也可以使用带学期信息的 JSON：

```json
{
  "termId": "2027-spring",
  "label": "2027 春季",
  "courses": []
}
```

其中 `courses` 内的课程字段需与 `app/courses.json` 保持一致；如果没有提供 `termId` 或 `label`，网页会根据文件名建立学期名称。

## 导入 WakeUp 课程表

1. 先在课程列表中确认已选课程、班次、上课地点、星期、节次和周数均符合学校最终安排。
2. 点击右上角“导出 WakeUp CSV”，保存生成的 CSV 文件。
3. 打开 WakeUp 课程表的导入功能，选择该 CSV 文件并检查导入预览。
4. 如学校课表或班次有调整，请重新核对后再导入；本工具不会替代学校正式选课系统。
